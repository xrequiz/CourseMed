# התחנה השביעית — הכנה למבחני האישיות לרפואה 🩺

אתר תרגול למבחני האישיות לקבלה ללימודי רפואה בישראל (מו"ר / מרק"ם / מר"ב, ומסלולי צפת וחיפה):

- **שאלון ביוגרפי** — כתיבה עם טיימר ומשוב מעריך AI, כולל "בנק אירועים" אישי שנשמר בדפדפן
- **סימולציות מול שחקן AI** — 6 תרחישים בינאישיים עם תחקיר מעריך בסוף
- **תחנות דילמה וראיון** — עם טיימר ומשוב
- **יום מבחן מלא** — 6 תחנות ברצף עם תחקיר מסכם
- **ראיונות צפת (בר-אילן) וחיפה** — מול צוות מראיינים AI
- **שאלון של"ו** — תרגול פורמט, פריטי תקפות וצמדי היגדים
- **מדריך, טיפים וצ'קליסט מוכנות**

## ארכיטקטורה

- **צד לקוח:** React + Vite + Tailwind CSS (עברית, RTL), כולל קלט קולי (Web Speech API) בדפדפנים תומכים.
- **צד שרת:** פונקציית Serverless אחת (`api/chat.js`) שמתווכת מול ה-API של Anthropic (Claude) ומזרימה את התשובות (streaming).
  **מפתח ה-API נשמר אך ורק בצד השרת** (משתנה סביבה) — הוא לעולם לא נחשף לדפדפן.
- **כל ה-system prompts נמצאים בשרת בלבד** (`api/_prompts.js`): הלקוח שולח רק `promptId`, כך שה-endpoint הציבורי לא יכול לשמש כפרוקסי חופשי ל-Claude.
- **Rate limiting** מובנה ב-`api/chat.js` (פר-IP) כהגנה נוספת מפני ניצול לרעה.
- **אחסון אישי:** `localStorage` בדפדפן בלבד (בנק אירועים, צ'קליסט, היסטוריית משובים) — שום מידע אישי לא נשמר בשרת. בכניסה מזינים שם, וההתקדמות נשמרת בנפרד לכל פרופיל באותו דפדפן.

## פריסה ל-Vercel (חינמי) — מומלץ

1. היכנסו ל-[vercel.com](https://vercel.com) והתחברו עם חשבון GitHub (חינם, תוכנית Hobby).
2. **Add New → Project** ובחרו את הריפו הזה. Vercel מזהה Vite אוטומטית — אין צורך לשנות הגדרות build.
3. לפני הלחיצה על Deploy, פתחו **Environment Variables** והוסיפו:
   - `ANTHROPIC_API_KEY` — מפתח API מ-[console.anthropic.com](https://console.anthropic.com/settings/keys)
   - (אופציונלי) `CLAUDE_MODEL` — ברירת מחדל: `claude-sonnet-4-6`
4. לחצו **Deploy**. תוך כדקה תקבלו כתובת `https://<project>.vercel.app` עם HTTPS.

> ללא `ANTHROPIC_API_KEY` האתר עולה ועובד, אבל כפתורי המשוב והסימולציות יציגו הודעת שגיאה ברורה.

### עלויות ובטיחות תקציב

- **האחסון עצמו חינמי לחלוטין** (Vercel Hobby).
- **השימוש ב-API של Anthropic בתשלום לפי שימוש** — זו העלות היחידה. תרגול אישי טיפוסי עולה אגורות בודדות לסשן.
- מומלץ מאוד להגדיר **Spend Limit** (תקרת הוצאה חודשית) ב-Console של Anthropic תחת Billing — כך אי אפשר לחרוג מהתקציב גם אם מישהו ינצל את האתר לרעה.
- בצד השרת יש מגבלות מובנות (אורך שיחה, מספר הודעות, תקרת טוקנים לתשובה) שמקטינות אפשרות לניצול לרעה.
- אם האתר ציבורי ופתוח לכולם, שקלו להוסיף הגנה נוספת: [Vercel Deployment Protection](https://vercel.com/docs/security/deployment-protection) (סיסמה/SSO) או rate-limiting.

## פיתוח מקומי

```bash
npm install
npm run dev          # צד לקוח בלבד (קריאות AI ייכשלו ללא שרת)
```

לבדיקת ה-API מקומית עם פונקציות Serverless:

```bash
npm i -g vercel
ANTHROPIC_API_KEY=sk-ant-... vercel dev
```

## מבנה הפרויקט

```
├── api/
│   ├── chat.js          # פרוקסי צד-שרת ל-Anthropic API: ולידציה, rate limit, streaming
│   └── _prompts.js      # כל ה-system prompts (לא נחשף כ-route)
├── src/
│   ├── App.jsx          # ניווט ומעטפת
│   ├── theme.js         # צבעים ופונטים
│   ├── data.js          # תוכן: שאלות, תרחישים, טיפים
│   ├── lib/
│   │   ├── api.js       # קריאות לשרת עם streaming
│   │   └── store.js     # localStorage + היסטוריית תרגול
│   ├── components/      # רכיבי המסכים (ביוגרפי, סימולציה, יום מבחן...)
│   ├── main.jsx
│   └── index.css        # Tailwind
└── index.html
```
